# CodeAlpha Data Redundancy Removal System

## Project Overview
The Data Redundancy Removal System is a Python-based project that detects and prevents duplicate data entries using an SQLite database.

## Objective
The main objective of this project is to identify duplicate records and store only unique data in the database.

## Technologies Used
- Python
- SQLite Database

## Features
- Detects duplicate data entries.
- Prevents duplicate records from being stored.
- Validates new data before insertion.
- Stores unique and verified records.
- Improves database accuracy and efficiency.

## How It Works
1. Connects to the SQLite database.
2. Accepts user information.
3. Checks whether the information already exists.
4. Prevents duplicate entries.
5. Stores unique records in the database.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

   python main.py

## Expected Result
The system successfully stores unique records and displays a message when duplicate data is detected.

## Conclusion
This project helps maintain accurate data by identifying and preventing duplicate records in a database.
